HOW TO GET THE DOWNLOAD WEBSITE LIVE (free, about 5 minutes, no coding)
1. Make a free account at github.com and create a new PUBLIC repository.
2. Upload everything in this folder to it (Add file > Upload files). Include the hidden .github folder.
3. Repo Settings > Pages > set Source to "GitHub Actions".
4. Open website/index.html, replace YOUR-USERNAME/YOUR-REPO in the Download link with yours, and commit.
5. Wait about 5 minutes (Actions tab). Your site is at https://YOUR-USERNAME.github.io/YOUR-REPO/
   and the Download button gets Voice-AI-Setup.exe, built on Windows by GitHub.
